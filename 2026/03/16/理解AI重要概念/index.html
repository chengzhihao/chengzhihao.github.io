理解AI重要概念

如今，AI 技术层出不穷，每天都能看到很多的资讯和工具诞生，但最根本的本质离不开 LLM、agent、mcp, skills。

下面通过一个简单示例来说明。 （咨询deepseek，给了我一个例子，大致上说明了 LLM、agent、mcp、skills

之间的关系）

LLM（大语言模型）：天才厨神“小灵”

比喻角色：被困在厨房里的厨神

小灵的特点：

  • 脑子里装着全世界的菜谱，读过万卷书
  • 能跟你聊美食哲学，回答任何烹饪问题
  • 但：没有腿，没有眼睛，没有手，没有钱
  • 只能在你提供的食材（你的提问）基础上加工（生成文字）

他的价值：餐厅的核心智慧，美味的来源
他的局限：困在厨房里，无法触碰现实世界

你能问他“鱼香肉丝怎么做”，但不能让他“去菜市场买根葱”。

Agent（智能代理）：全能店长“阿智”

比喻角色：指挥中心、决策大脑

阿智的任务：处理一个复杂目标——“用100块钱，做一顿让隔壁老王一家三口满意的晚餐”

阿智的工作流程：

阿智的核心能力：

  • 规划拆解：把大目标变成小任务
  • 决策判断：什么时候该做什么
  • 工具调用：知道自己做不到，但知道谁能做到

MCP（模型上下文协议）：万能插座“通通”

比喻角色：标准化的接口协议 + 通用说明书

为什么需要通通？

餐厅生意越来越好，阿智需要调用的工具越来越多：

  • 美团买菜、饿了么、京东到家
  • 计算器、日历、闹钟
  • 地图导航、支付系统

问题来了：每个APP的接口都不一样，对接一个学一个，阿智要累死了！

通通（MCP）的解决方案：

通通（MCP）的价值：

  • 统一接口：所有工具都按同一标准接入
  • 即插即用：新工具来了，直接插上就用
  • 上下文传递：把“100块预算”这个信息自动带给每个工具

通通让阿智从“学习每个工具”变成“只学通通一个”，效率飙升！

Skills（技能）：餐厅里的所有员工

比喻角色：真正动手干活的各个岗位

这是之前缺失的关键一块！ 没有 Skills，阿智只是“知道该干什么”，但没人真的去干。

我们的餐厅里有哪些员工（Skills）？

技能名称 岗位角色 具体职责
搜索技能 信息检索员 上网查“鸡翅当前价格”、“哪家超市便宜”
计算技能 会计 计算总价：鸡翅20 + 蔬菜8 + 鸡蛋5 = 33元
支付技能 收银员 完成线上支付，确保钱花出去
下单技能 采购员 在美团买菜上下订单，指定收货地址
日历技能 秘书 把“晚餐时间”记在日程上，设置提醒
地图技能 跑腿小哥 查询从餐厅到老王家的最佳路线
通知技能 通讯员 给老王发消息：“晚餐已在路上，30分钟到”

Skills 的特点：

  • 单一职责：每个技能只做一件事，但做到极致
  • 可复用：今天买鸡翅用采购技能，明天买鱼也用它
  • 标准化：都按照 MCP 的标准开发，插头一致

完整版：智能餐厅运转全流程

一句话总结每个角色

概念 比喻角色 核心作用 一句话理解
LLM 厨神小灵 思考、生成 大脑——会想，但动不了
Agent 店长阿智 规划、决策 指挥官——知道怎么拆解任务、调用谁
MCP 插座通通 标准化连接 神经系统——让指令和数据无障碍流动
Skills 全体员工 具体执行 手脚——真正把事干了

核心思想

LLM 提供了智慧（能想）
Agent 提供了智能（会想怎么干）
Skills 提供了能力（能干）
MCP 提供了连接（让能干的事都能被调用）

用一句话说清楚整个系统：

Agent（指挥官）通过 MCP（万能插座）调用各种 Skills（专业技能），让 LLM（聪明大脑）的想法变成现实，完成复杂任务。

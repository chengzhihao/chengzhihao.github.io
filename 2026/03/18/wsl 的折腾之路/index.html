wsl启动失效后的折腾

Posted on 2026-03-18 In Linux

wsl是什么

WSL 的全称是 Windows Subsystem for Linux（适用于 Linux 的 Windows 子系统）。
简单来说，它让你可以在 Windows 系统上直接运行 Linux，而不需要安装虚拟机或双系统。

用它的原因

在windows10桌面环境下，同时又具备了linux子系统，随意切换使用爽的很。

灾难来临

可就在今天， 当我兴致勃勃的通过终端工具连接时，没有报错， 界面一闪而过。 我当时脑海中闪过一丝不好的念头，完蛋了。 数据要丢了。

心态崩了

通过反复查找资料，折腾解决办法。 全部失败。
最后，通过 wsl –update 更新wsl, 也确实可以，最后直接到了系统安装界面， 一步步走完，
安装成功，进去系统里一看， 之前的home目录下的用户不见了， 数据全部丢弃。人当时直接蒙了。
后面试着各种办法， 都没有成功恢复数据，全部希望破灭了。

心死道生

意识数据备份的重要性。 最后，结合我的场景，设计了如下备份要点。

  • 备份整个 /home 目录下数据
  • 将备份数据写入windows系统下的其他盘符下，linux下盘符目录在 /mnt/盘符下
  • 备份过程的中，输出提示性信息，按照颜色级别进行标注
  • 备份过程中，自动生成备份报告
  • 备份成功后，清理旧的备份文件
  • 可配置自动执行任务，每日定时备份一次
